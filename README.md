 Игра "Угадай число" (GUI)

Моя первая игра на Python с современным графическим интерфейсом, созданная с использованием библиотеки `CustomTkinter`. 

Описание игры
Компьютер загадывает случайное число от 1 до 100. У игрока есть 7 попыток, чтобы его угадать. После каждой неудачной попытки игра подсказывает, больше или меньше загаданное число.

 Как играть
1. Скачайте архив `GuessTheNumber_v1.0.zip` из раздела **Releases** (справа на странице).
2. Распакуйте архив в любую папку.
3. Запустите файл `GuessTheNumber.exe`.
4. Нажмите "Начать игру" и попробуйте угадать число!

 Технологии
*   **Python 3**
*   **CustomTkinter** (для современного дизайна)
*   **Random** (для генерации чисел)
